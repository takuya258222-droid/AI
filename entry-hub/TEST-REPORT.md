# 検証結果（2026-10-25）

## 確認済み
- Next.js本番ビルド成功（全ルート生成、型検査通過）。
- 自動テスト33件成功。入力・全経験月数・匿名推薦文・PDF初期値・SQL権限・採番・重複送信防止・通知処理・予約競合・ステータスとメモ保存を検証。
- PostgreSQL互換PGliteで実際にスキーマと制約を実行。
- メール成功／失敗後の再送／二重処理防止、Google予定の1時間登録／競合／失敗後の再試行／既存予定の復旧は外部APIを模擬して検証。
- 日本語PDFのサンプルを生成し描画を確認。

## 未完了・公開前に必要
- 本番SupabaseへのSQL適用、スタッフ登録、本番環境変数の設定。
- Renderの対象ワークスペース確認とソース用Gitリポジトリ準備。公開URLは未発行。
- Resendの送信ドメイン・APIキー設定後、指定受信者への実メール到着を確認すること。
- Google OAuthと対象Calendar ID設定後、管理画面「連携テスト」で1時間のテスト予定を作成して確認すること。
- ブラウザーによる操作試験はプレビュー環境のアクセス制約により完了していない。公開前にスマホで全4ステップの入力・送信、管理側の検索・保存・コピー・PDFを確認すること。
- カレンダーはアプリから登録しGoogleの空き状況を確認する連携。Google側の編集をアプリに逆同期する機能は含まない。
- 実SMSの自動送信サービスは含まない。短縮URL付き文面コピーと端末SMSアプリ起動に対応。
