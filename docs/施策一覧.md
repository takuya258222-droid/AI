# Botの施策一覧（CV改善）

| 施策 | 何をするか | 配信数（月200通の枠）を使うか |
|---|---|---|
| 「登録した？」ボタン | 診断結果の下に「登録した／まだ迷ってる／あとで登録する」を表示。押した内容で返信を分岐し、週次レポートに集計 | 使わない（返信） |
| 診断結果の再表示 | 「結果」と送る／メニューから、診断結果と紹介リンクをもう一度表示（診断から30日間） | 使わない（返信） |
| 面談・選考のポイント | 職種と年代を選ぶと、その職種の5つのポイント＋年代ごとの傾向＋その職種・年代に合うエージェント（診断と同じ振り分け。ASSIGNは先頭）を返す。診断のあとのボタンからは、診断の職種・年代でそのまま開く。noteの更新は不要（`config/tips.json`）。選考サポートの記載があるサービスは、その内容を表示 | 使わない（返信） |
| 体験記に最新のnote | 「転職体験記」に、noteのRSSから最新5件を自動表示（30分キャッシュ。取得できなければ従来の事例カード） | 使わない（返信） |
| 新着noteの週次配信 | 希望した人だけ。土曜の10〜15時の間に、その職種の新着があるときだけ送信（1回のCronで送る人数に上限があるため、数時間に分けて送信） | 使う（1人あたり週1通まで） |
| 月末の締切リマインド | 月末の最後の3日間（12〜20時）、診断したがスクショ未送信の人へ1回だけ | 使う（優先して送る） |
| フォロー3通目 | 診断の約1日後・約4日後・約7日後（「迷っている方へ」） | 使う |
| あいさつ文のA/B | ユーザーIDでA（詳しい）/B（短い）に振り分け。友だち追加→開始→完了→スクショを週次レポートで比較 | 使わない |

## 配信数の管理（無料プランの月200通）
- Cronからの配信（リマインド・フォロー・新着note）は、月の通数を自分で数えます。運営者向けの通知用に30通を残し、超える分は送りません。
- 優先順位は「締切リマインド → フォロー → 新着note」です。
- 有料プランにしたら、環境変数 `PUSH_MONTHLY_LIMIT`（例：5000）と、必要なら `PUSH_RESERVE` を設定してください。
- 「統計」コマンドと週次レポートに、今月の配信数（例：42／200通）が出ます。

## 1回のCronで送る人数の上限（無料プランのCPU時間の制限）
- Cloudflare無料プランは、1回の処理のCPU時間が10ミリ秒までのため、Cronは1回で最大6人までに送ります（残りは次の時間に）。
- 有料プランにしたら、環境変数 `CRON_MAX_SENDS`（例：100）を増やせます。

## 保存する情報（プライバシー表記も更新済み）
- 診断の記録（ユーザーID・診断の区分・送信段階）: 診断から最大30日。「配信停止」・ブロック・スクショ送信で削除。
- 新着noteの購読（ユーザーID・希望の職種）: 最大180日。「配信停止」・ブロックで削除。
- 「配信停止」と送ると、診断の記録と購読の両方を削除します。

## 見送った施策
- リンクごとのクリック計測（自前の転送URL）: ASPの規約・成果計測への影響が読めないため。
- 友だち紹介で抽選口数を増やす: 懸賞の法律面の確認が必要なため。
