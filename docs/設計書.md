# 設計書｜転職LINE公式アカウント（なぎ【正しい転職エージェントの使い方】）

この設計書は、実際に稼働する Bot と設定ファイルから**自動生成**しています（`npm run docs`）。
文面・ボタン・分岐は Bot に実装済みで、LINE管理画面で手動設定が必要な項目は「【管理画面で設定】」と明記しています。

**コンセプト**：「転職エージェントを紹介する広告LINE」ではなく、「自分に合う転職サービスを30秒で診断できるLINE」。
紺×ゴールドの統一デザイン／質問はすべてタップ／診断結果に「選ばれた理由」を明示／運営者・選定基準・広告表記を公開。

---

## STEP 1｜アカウント基本設定
【設定場所】LINE Official Account Manager → 設定 →「アカウント設定」「プロフィール」【管理画面で設定】

| 項目 | 設定内容 |
|---|---|
| アカウント名 | 現状の「なぎ【正しい転職エージェントの使い方】」を推奨（検索性・信頼感。変更不要） |
| ステータスメッセージ | 30秒で、あなたに合う転職サービスを。診断は無料・タップだけ |
| プロフィール説明 | なぎが運営する、転職サービスの診断アカウントです。\n職種・年代・年収帯・重視したいことに合わせて、対象条件に合うサービスだけを厳選してご案内します。\n運営：元転職エージェント。営業として9年で、支援成約800名・相談8,000名超。現在は、人材紹介会社の立ち上げ支援コンサルタントとして20社以上に関わり、優良なエージェントもそうでないエージェントも知る立場から、サービスごとの違いをお伝えしています。医療福祉・M&A・VC・PEファンド、営業（SaaS・IT・メーカー）、製造、建築など、幅広い領域を支援してきました。\n※当アカウントは、ご紹介するサービスの紹介リンク経由の登録・利用に応じて、各社から報酬を受け取る場合があります（広告・PR）。 |
| アイコン | `assets/avatar.png`（640×640・紺×ゴールドのモノグラム「N」）をアップロード |
| 認証済アカウント | 申請を推奨（審査あり）。プロフィールに認証バッジが付き信頼性が上がり、フォロワー数などの統計APIも使えるようになります |

|---|---|

| 抽選再 ／ 抽選今月再 | 引き直し（応募画像が無効だったとき） |
| 当選連絡 | 直近の当選者に、当選のご連絡を自動送信 |
| 統計 ／ 統計30 | 直近7日／30日の集計（流入経路別・職種別つき） |
| 経路リンク | 流入経路つきリンク（/l/経路名）の作り方 |
| 管理 | コマンド一覧 |

