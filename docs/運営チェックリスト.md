- [ ] **リンクの媒体登録**：使用しているのは「Threads」用のリンクです。LINE公式アカウントでの利用が可能か、LINE用のメディア登録・リンク発行が必要かをA8で確認してください（必要ならリンクを差し替え：`sync-links.py --tab` で別タブを指定可）。
- [ ] **キャンペーンの運用ルール（★の仮置き）を確定**：`config/campaign.json`（応募口数・抽選日・当選連絡の期限・賞品のお渡し方法）。確定後 `npm run pages && npm run docs` で規約ページに反映。

## 🟢 運用
- 月間メッセージ数：**返信（診断・応答）は通数に含まれません**。プッシュ（診断後フォロー・運営への通知）のみ対象です。フリープランは月200通。診断が月100件を超える見込みなら、プラン変更を検討してください。
- 当選連絡・抽選は月1回、管理画面のチャット（画像つきトーク）から実施。
- 運営者のみ、LINEで「統計」と送ると、直近7日の集計（友だち追加・診断開始・診断完了・スクショ数）が見られます（`ADMIN_USER_ID` 設定時）。
- 掲載サービスの条件変更・提携終了に備え、月1回は `docs/サービス振り分け表.md` の対象条件を見直してください。

## 🎯 毎月の抽選のしかた（運営者のLINEから）
1. 月末を過ぎたら、LINEで「**抽選**」と送る（前月分から3名を自動抽選）
2. 当選候補の応募画像を、管理画面のチャットで確認
3. 問題なければ「**当選連絡**」と送る（当選者3名に自動でご連絡）。無効な応募があれば「**抽選再**」で引き直し
4. 当選者から返信が来たら、トークでお渡し方法をご案内
※運営者のコマンドは、Cloudflareに `ADMIN_USER_ID`（あなたのLINE userId）が登録されているアカウントからのみ有効です。
