# 公開手順（Botを動かして、LINEにつなぐ）

Botは **Cloudflare Workers（無料プラン・商用利用可・コールドスタートなし）** で動かす構成です。
所要時間の目安：15〜20分。

## 0. 事前に必要なもの
- Cloudflareの無料アカウント（https://dash.cloudflare.com/sign-up ）
- LINE Developers の **チャネルシークレット** と **チャネルアクセストークン（長期）**
- このリポジトリ（GitHub）。※ブランチの内容を `main` にマージしておくと、以降の更新が自動反映されます

## 1. Cloudflare にデプロイ（ダッシュボードだけで完了）
1. Cloudflare → **Workers & Pages** → **Create** → **Import a repository** で GitHub を連携し、このリポジトリを選ぶ
2. 設定はそのまま（Build command は空、Deploy command は `npx wrangler deploy`）→ **Deploy**
3. 完了すると `https://career-line-bot.<あなたのサブドメイン>.workers.dev` が発行されます（これがBotのURL）
   - 画像・規約ページも同じURLから配信されます（例：`/img/welcome.jpg`、`/legal.html`）
   - 診断後フォロー配信・集計用のKV（`STORE`）は、初回デプロイで自動作成されます

## 2. 秘密情報を登録
Cloudflare → 作成したWorker → **Settings → Variables and Secrets** に、種類「Secret」で登録：

| 名前 | 値 |
|---|---|
| `LINE_CHANNEL_SECRET` | チャネルシークレット |
| `LINE_CHANNEL_ACCESS_TOKEN` | チャネルアクセストークン（長期） |
| `ADMIN_USER_ID`（任意） | 運営者のLINE userId（LINE Developers → チャネル基本設定 →「あなたのユーザーID」）。スクショ受信の通知と「統計」コマンドが使えます |

## 3. LINEにWebhookを登録
1. LINE Developers → Messaging API設定 → **Webhook URL** に `https://…workers.dev/webhook` を入力 → **検証**（成功と表示されればOK）
2. **Webhookの利用** を **オン**

## 4. 応答設定（LINE Official Account Manager）
設定 → 応答設定：
- あいさつメッセージ：**オフ**（Botが送信）
- 応答メッセージ：**オフ**（Botが応答）
- Webhook：**オン**　／　AI応答メッセージ：**オフ**
- 応答モード：チャット（現状のままでOK。運営が管理画面から手動返信もできます）

## 5. リッチメニューを全員に表示
```
LINE_CHANNEL_ACCESS_TOKEN=xxxx npm run richmenu:activate
```
（Claudeに依頼する場合は、Botの公開が済んだことを伝えてください）

## 6. 動作確認（ご自身のLINEで）
友だち追加 → あいさつ → 診断 → 結果 → リンク → スクショ送信 → 受付返信／リッチメニューの2タブ／体験記パネル

## 別の方法
### Claudeにデプロイまで任せる
Cloudflareで API トークン（テンプレート「Edit Cloudflare Workers」）を作成し、環境の Secrets に `CLOUDFLARE_API_TOKEN` と `CLOUDFLARE_ACCOUNT_ID` を登録すれば、デプロイからWebhook登録まで自動化できます。

### コマンドで行う場合
```
npm install
npx wrangler login
npx wrangler secret put LINE_CHANNEL_SECRET
npx wrangler secret put LINE_CHANNEL_ACCESS_TOKEN
npm run deploy
```

### Render / Railway などのNode環境
`npm start`（`src/adapters/node-server.mjs`）で起動し、環境変数 `LINE_CHANNEL_SECRET` / `LINE_CHANNEL_ACCESS_TOKEN` を設定します。
※KVが無いため、診断後のフォロー配信と集計は無効になります（診断・応答は同じ）。無料枠は一定時間で停止し、初回応答が遅くなる場合があります。

## 更新のしかた
| やりたいこと | 手順 |
|---|---|
| サービスの追加・停止・文言変更 | `config/services.src.json` を編集 → `python3 scripts/sync-links.py <リンク一覧.xlsm>` → `npm test` → push |
| キャンペーン規約の変更 | `config/campaign.json` を編集 → `npm run pages && npm run docs` → push |
| 画像の作り直し | `npm run assets`（リッチメニュー画像を変えたら `npm run richmenu:activate`） |
| メッセージの検証 | `LINE_CHANNEL_ACCESS_TOKEN=… npm run validate`（LINEの検証APIで全メッセージをチェック） |
