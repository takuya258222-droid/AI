# 集客テンプレート（note・Threads・X に貼るだけ）

## 仕組み
`https://career-line-bot.career-line-bot.workers.dev/l/経路名` のリンクを踏むと、LINEのトークが「30秒診断を始める【経路名】」と**入力済みの状態**で開きます（友だち未追加の方は、追加の案内 → トークへ）。
送信すると診断が始まり、**経路ごとに「クリック → 診断開始 → 診断完了 → スクショ」**が集計されます。
職種つきのリンク（`?job=`）なら、**職種の質問を飛ばして年代から**始まります。

| 職種 | リンクの付け方 |
|---|---|
| 看護師 | `…/l/経路名?job=nurse` |
| 介護職 | `?job=care` |
| 薬剤師 | `?job=pharm` |
| 保育士 | `?job=child` |
| IT | `?job=it` |
| 営業 | `?job=sales` |
| 製造 | `?job=mfg` |

## 経路名のつけ方（例）
- note：記事ごとに `note-記事の略称`（例：`note-nurse1`、`note-kaigo2`）
- Threads：`threads`（プロフィール）、`threads-pin`（固定投稿）
- X：`x` ／ プロフィール：`profile`
※英数字・ハイフン・アンダースコア、24文字まで。LINEで「**経路リンク**」と送ると、使い方が返ってきます。

```
https://career-line-bot.career-line-bot.workers.dev/l/note-記事名
```


## 運用のコツ
1. **1投稿・1記事につき、1つの経路名**にする（効いた投稿が分かります）
2. 毎週月曜の朝に届く**週次レポート**で、経路別の「クリック→開始→完了→スクショ」を確認
3. クリックは多いのに開始が少ない経路 → 誘導文とリンクの相性が悪い／完了が少ない → 質問の見直し／スクショが少ない → 結果カード・キャンペーンの見せ方を強化
4. 広告表記（PR）は、必ず入れてください（ステルスマーケティング規制）
